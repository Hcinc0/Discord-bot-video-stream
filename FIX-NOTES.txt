HCINCO v2.2 MEDIA FIX
=====================

FIXED:
- SoundCloud client_id crash from the previous media resolver.
- SoundCloud Set/Playlist links now play the first item.
- YouTube/SoundCloud extraction moved to yt-dlp.
- Media is resolved before Discord voice join.
- Bot no longer leaves immediately just because media extraction failed.
- Playback errors now return readable messages.
- Bot stays in voice after playback finishes until Stop & Leave.

MEDIA ENGINE:
- yt-dlp: auto-downloaded from official GitHub release on first media playback if missing.
- FFmpeg: provided by ffmpeg-static npm dependency.

NOTE:
Official Discord bot APIs do not provide video screen share / Go Live for bots.
This project plays audio in Discord Voice.
