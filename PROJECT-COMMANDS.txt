Hcinco Discord Voice Dashboard v2.1 - Commands
===============================================

RECOMMENDED WINDOWS START:
  START-HCINCO.bat

CLEAN REINSTALL ON WINDOWS:
  CLEAN-INSTALL-WINDOWS.bat

MANUAL SETUP:
  node -v
  npm install --prefix server
  npm install --prefix client

RUN BOTH:
  npm run dev

RUN BACKEND ONLY:
  npm run backend
  # or: npm run dev --prefix server

RUN FRONTEND ONLY:
  npm run frontend
  # or: npm run dev --prefix client

CHECK BACKEND:
  http://127.0.0.1:4000/api/health

DASHBOARD:
  http://localhost:5173

PRODUCTION FRONTEND BUILD:
  npm run build

VOICE DEPENDENCY REPORT:
  npm run doctor

Requirements:
  Node.js 22.12.0+
  Internet access for npm install and remote media
  Discord bot with View Channels + Connect + Speak
