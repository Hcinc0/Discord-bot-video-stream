راهنمای رفع خطای HTTP 502 / ECONNREFUSED
=========================================

در نسخه v2.1 این مشکل اصلاح شده است.

روش پیشنهادی در ویندوز:
1) اگر نسخه قبلی پروژه را داشتی، یک بار CLEAN-INSTALL-WINDOWS.bat را اجرا کن.
2) سپس START-HCINCO.bat را اجرا کن.
3) دو پنجره باز می‌شود:
   - Hcinco Backend - KEEP OPEN
   - Hcinco Frontend - KEEP OPEN
4) هر دو پنجره را باز نگه دار.
5) سایت به صورت خودکار روی http://localhost:5173 باز می‌شود.

اگر بک‌اند بالا نیاید، Launcher سایت را باز نمی‌کند و به تو می‌گوید پنجره Backend را بررسی کنی.

آدرس تست بک‌اند:
http://127.0.0.1:4000/api/health

نسخه Node.js باید 22.12.0 یا جدیدتر باشد.
برای دیدن نسخه:
node -v

نکته امنیتی:
Discord Bot Token را داخل چت یا GitHub منتشر نکن. توکن را فقط از Settings خود داشبورد وارد کن.
